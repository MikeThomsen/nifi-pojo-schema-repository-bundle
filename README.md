# NiFi POJO Schema Registry

A NiFi controller service that provides record schemas generated from Java classes. Point it at one or more JAR files, map schema names to class names, and record readers and writers can look the schemas up by name, just like any other `SchemaRegistry`.

## Requirements

- Apache NiFi 2.12.0 or later in the 2.x line
- Java 21

## Building

```
mvn clean verify
```

The NAR is written to `nifi-pojo-schema-repository-nar/target/nifi-pojo-schema-repository-nar-<version>.nar`. Copy it into NiFi's `lib/` or `extensions/` directory.

## Configuration

Add a **PojoSchemaRegistryService** controller service.

| Property | Description |
|---|---|
| Extension JARs | Comma-separated list of JAR files, or directories of JAR files, that contain the classes. Supports environment variable expressions. |
| Schema Generation Strategy | How schemas are generated for classes that were not generated by the Avro compiler. `Jackson` (default) or `Avro Reflection`; see below. |

Each **dynamic property** defines one schema:

- **Name**: the schema name readers and writers will ask for, for example `transaction`
- **Value**: the fully qualified class name, for example `com.example.model.FinancialTransaction`

Class names are checked against the configured JARs when the service is validated, so a typo shows up before you enable the service.

### Which schema is used

1. **Avro-generated classes** (anything with a `public static Schema SCHEMA$` field) use their embedded schema as-is.
2. **Everything else** goes through the configured strategy:

| | Jackson | Avro Reflection |
|---|---|---|
| Field discovery | Getters and Jackson annotations (`@JsonProperty`, `@JsonIgnore`, ...) | Fields and Avro annotations (`@AvroName`, `@AvroAlias`, `@AvroIgnore`, ...) |
| Nullability | Every reference-type field is nullable | Fields are non-null unless annotated `@Nullable` |
| `java.time` types | `Instant` becomes `timestamp-millis`, read by NiFi as `TIMESTAMP` | `Instant` → `TIMESTAMP`, `LocalDate` → `DATE`, `LocalTime` → `TIME`. `LocalDateTime` becomes Avro `local-timestamp-millis`, which NiFi reads as `LONG` (milliseconds) |

Pick **Jackson** for classes that are already serialized with Jackson, and **Avro Reflection** when you want Avro's annotations and strict nullability.

## Security

Enabling the service loads classes from the configured JARs, and reading an Avro-generated class's schema runs that class's static initializer. The service is therefore marked `@Restricted`, and users need the **execute code** and **reference remote resources** permissions to add or configure it.
